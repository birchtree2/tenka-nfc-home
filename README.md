# xxxxP · NFC Personal Page

A static, mobile-first personal page that can be opened from an NFC card. No build step or backend.

## Edit your details

- Main profile copy, display name, QQ/Bilibili/Xiaohongshu and music song ID: `index.html`
- Colors, type and responsive layout: `styles.css`
- Copy buttons: `script.js`

The display name is left as `xxxxP`; the Xiaohongshu ID is marked `账号待补` until provided. QQ is shown as a copyable ID.

## Deploy

The `main` branch deploys through GitHub Actions to GitHub Pages. Intended custom domain: `umi-cv.com`. DNS setup steps are in [DOMAIN_SETUP.md](DOMAIN_SETUP.md); the custom domain has been added in GitHub, and the Cloudflare apex records still need to be created.
